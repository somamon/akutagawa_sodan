# 芥川龍之介 作品コーパス

AI芥川の回答品質を上げるため、芥川の全作品テキストを置くディレクトリ。

## 構成

```
corpus/
├── raw/           # 入手したままの原文（Shift_JIS・ルビ付き、作品IDプレフィックス）
├── processed/     # 整形済みテキスト（アプリ・スクリプトが読むのはこちら）
└── manifest.json  # 取得した作品の一覧（ID・タイトル・文字数・パス）
```

## 取得・更新方法

```bash
npm run fetch:corpus
```

`scripts/fetch-corpus.mjs` が青空文庫の公式インデックスCSVから著者=芥川龍之介の
全作品をダウンロードし、raw保存 → UTF-8変換 → ルビ・注記・書誌情報除去まで行う。
再実行すれば上書き更新される。

注意: 同一作品の新字新仮名版と旧字旧仮名版が別作品として両方含まれる
（例: 『羅生門』）。用途に応じて manifest.json でフィルタすること。

## 入手元

[青空文庫の芥川龍之介 作家ページ](https://www.aozora.gr.jp/index_pages/person879.html)（全作品パブリックドメイン）。

## raw/ の注意

青空文庫のテキストはそのままでは使えない：

- 文字コードが **Shift_JIS**（UTF-8への変換が必要）
- ルビ記法 `漢字《かんじ》` や `｜` が混入
- 入力者注 `［＃ページの左右中央］` などの注記が混入
- 冒頭・末尾に書誌情報ブロック（`----` 区切り）がある

## processed/ の規約

- 文字コード: **UTF-8**、拡張子 `.txt`
- ルビ・注記・書誌情報ブロックを除去した本文のみ
- ファイル名: `作品名.txt`（例: `羅生門.txt`、`侏儒の言葉.txt`）

## 想定する使い道

1. **プロンプト強化**: 代表作の抜粋や警句集（特に『侏儒の言葉』）を `server/utils/akutagawaPersona.ts` のシステムプロンプトに組み込み、文体・引用の精度を上げる
2. **RAG**: 相談内容に関連する作品箇所を検索してプロンプトに注入する（Supabase の pgvector を使う場合は要マイグレーション追加）
